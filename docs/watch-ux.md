# TimeW: UX-контракт Watch S5

## Принцип

Часы — это быстрый голосовой пульт, а не маленький телефон. На круглом экране
480×480 человек должен понимать состояние одним взглядом и попадать в основное
действие вслепую.

## Ограничения среды

- безопасная зона текста начинается с заметным отступом от края круга;
- минимальная интерактивная цель — примерно 68 px;
- ввод текста и `prompt.show` нельзя считать доступными на прошивке;
- статический `list-item` не используется: списки строятся через `for`;
- составные CSS-селекторы не используются, состояния получают отдельный класс;
- длинный ответ или заметка всегда имеют отдельный полный просмотр.

## Главный экран

Состояния:

| Состояние | Основное действие | Вторичное действие |
| --- | --- | --- |
| Готов | Говорить | Дом, Заметка |
| Запись | Готово / автостоп | Отменить |
| Думаю | Думаю | Отменить |
| Ответ | Ещё вопрос | Читать полностью |
| После света | готовый результат | Отменить действие |
| Ошибка | повторить разговор | открыть настройки |

Статус информирует, но не является скрытой кнопкой. Любая отмена должна быть
видимой крупной целью. Нижняя часть круга не используется для четырёх мелких
ссылок одновременно.

## Маршруты

- **Дом**: голосовая команда с `intent=home`; сервер распознаёт только точный
  свет + одну комнату, не передаёт неоднозначную команду в свободный AI-ответ.
- **Заметка**: отдельный экран диктовки, подтверждение распознанного текста,
  список с датой, полный просмотр по нажатию, явное удаление.
- **Ответ**: короткое превью на главном экране и прокручиваемый полный текст;
  кнопка озвучки отображается только при наличии `speechId`.
- **Настройки**: только пользовательские переключатели и проверка связи;
  адрес и токен показываются в диагностике, но не создают ложного поля ввода.
- **Диагностика**: человеческий прогресс и отмена; сырые TLS/module details
  уходят в отчёт, а не перегружают основной поток.

## Приёмка

1. Каждое частое действие имеет крупную цель и видимую подпись.
2. Нет dead controls: недоступная озвучка и неактивные подтверждения не
   показываются.
3. Текст не теряется из-за ellipsis: длинный ответ/заметка открываются целиком.
4. Сбой и отмена возвращают часы в понятное состояние без перезапуска.
5. Поведение, проверенное только сборкой, не считается доказанным на часах;
   физический прогон v38 обязателен перед окончательной приёмкой.
